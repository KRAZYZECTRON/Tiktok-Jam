# Demo transcripts

Generated by `py -m tools.demo_transcripts`. Every line below is real output from the shipped agent on a real public session — nothing is hand-written.

These exist because the interesting claim about this system is not its score, it is that its reasoning is inspectable turn by turn. `consistent products` is how many catalog items are still compatible with everything the shopper has said; `strategy` is the workflow chosen for that turn and why.
